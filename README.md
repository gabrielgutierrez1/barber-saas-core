# barber-saas-core
Plataforma SaaS PWA marca blanca para gestión de peluquerías. Sistema de reservas y pagos online con Mercado Pago. Arquitectura enterprise en NestJS/Next.js basada en microservicios y máxima seguridad con aislamiento de base de datos por cliente (DB-per-tenant). Despliegue contenerizado en Docker.
